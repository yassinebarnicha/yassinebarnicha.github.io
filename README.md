# yassinebarnicha.github.io

Page d'accueil de mes projets : **https://yassinebarnicha.github.io/**

Elle présente chaque projet (ce qu'il fait, comment il est construit, où voir le code), avec en tête
l'application [Calibration d'options Bitcoin](https://yassinebarnicha.github.io/calibration-btc-svjd/).

- Une seule page statique, `index.html`, sans bibliothèque ni police externe ; captures dans `img/`.
- Ajouter un projet : copier un bloc `<article class="carte">…</article>` dans la bonne section et changer le texte
  et le lien.
- Publiée par GitHub Pages depuis la branche `main`, dossier racine.
