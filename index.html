Bitcoin option calibration in the browser

Price, calibrate and analyse Deribit BTC options with jump and stochastic-volatility models, with no computing server and nothing to install: everything runs in the visitor's browser, on a computer or a phone.

  • JavaScript
  • Python
  • COS / PROJ
  • GitHub Actions
  • Interactive calibration: every slider reprices the whole chain of the day in a few milliseconds; five optimisers (classic and adaptive Nelder–Mead, differential evolution, hybrids).
  • Composable models: Black-Scholes, Heston, double Heston or Heston with variance jumps, combined with Merton, bi-lognormal, Kou, CGMY, Variance Gamma or NIG jumps.
  • Analysis: model Greeks against Black-76, 3-D volatility surface, gamma exposure (GEX).
  • Free pricer: options typed in or from a CSV file; exotics by Monte Carlo (Asian, barrier, lookback, American by Longstaff-Schwartz, free-formula payoff).
Demo Report Code Guide

The mathematics

Each model is defined by its characteristic function: a variance block times a compensated jump law. Prices come from the COS method (Fang–Oosterlee) or from PROJ (Kirkby) and are inverted into implied volatilities. The loss compares model and market in volatility or in price, with a choice of weights.

The engineering

A fully static site: the page carries its pricers and each day of data is a file loaded on demand. A GitHub Action downloads the Deribit chain every morning (public API) and republishes the site. The optimisation runs in 12 ms slices so that the screen stays fluid.

The validation

  • Put–call parity and the martingale property checked on all 28 models.
  • JavaScript pricer equal to the Python reference pricer to within 6·10⁻⁶ $.
  • Monte Carlo checked against the Fourier price (within 2 standard errors).
  • Time to expiry counted to the hour.
The application's eleven tabs, one by one
  1. 01Futures — the path of each future since its listing.
  2. 02Maturities — the choice of the expiries to calibrate.
  3. 03Target and filters — the target price (mark, mid), spreads, moneyness.
  4. 04Pricer — COS or PROJ, options typed in, CSV, exotics by Monte Carlo.
  5. 05Model — variance × jumps, with the dynamics written out.
  6. 06Parameters and optimiser — sliders, bounds, Feller condition, five optimisers.
  7. 07Loss — how the error is measured and weighted.
  8. 08Greeks — the model's Δ, Γ, Vega, Θ against Black-76.
  9. 09Vol surface — in 3-D, with the model's extrapolation.
  10. 10GEX — gamma exposure by strike, flip level, call and put walls.
  11. 11Settings — save, compare and export parameter sets.

Deep optimal stopping

Pricing high-dimensional Bermudan options with neural networks, after Becker, Cheridito and Jentzen (2019).

  • One network per exercise date learns the stopping rule.
  • Lower bound (learnt policy) and upper bound (dual), with a 95 % confidence interval.

C++ · DLL · Excel · JavaScript

Floating-strike lookback options

Unified C++ library, written with a partner, for European lookbacks under Black-Scholes, usable online.

  • Exact one-step engine: the extremum is drawn from the Brownian bridge, with no discretisation bias.
  • Time-stepping engine with the BGK correction, or an exact bridge per step (added, unbiased).
  • Greeks on common random numbers; dividend and seasoned options added.
